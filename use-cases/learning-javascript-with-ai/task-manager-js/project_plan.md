# Part 4 - JavaScript Mini-Project

## Project Name

Task Manager Web Application

## Project Description

The Task Manager is a simple web application that allows users to create and manage tasks.

The project will use HTML for the page structure, CSS for styling, and JavaScript for the application behaviour.

## Source Language

Python

## Target Language

JavaScript

## Concepts Learned

- JavaScript variables
- Functions
- Arrays
- Objects
- Conditional statements
- DOM manipulation
- Events
- Local storage

## Project Features

1. Add a new task
2. Display tasks
3. Mark tasks as completed
4. Delete tasks
5. Save tasks in the browser
6. Load saved tasks when the page opens

## Prompt Used

I want to build a Task Manager web application in JavaScript.

I'm coming from Python and have been learning JavaScript concepts including variables, functions, arrays, objects, events, DOM manipulation, and local storage.

Could you help me:

1. Break this project into small, manageable components.
2. Suggest which JavaScript and browser features I should use.
3. Outline the key files I need to create.
4. Identify challenges I may face coming from Python.

## AI Project Plan

### Component 1 - User Interface

Create an input field and an Add Task button.

### Component 2 - Task Creation

Read the user's task and add it to a JavaScript array.

### Component 3 - Task Display

Display every task as a list item on the webpage.

### Component 4 - Task Completion

Allow the user to mark a task as completed.

### Component 5 - Task Deletion

Allow the user to remove a task.

### Component 6 - Local Storage

Save the tasks in the browser so they remain available after the page is refreshed.

## Files Required

- `index.html` for the page structure
- `style.css` for the page design
- `script.js` for the application logic
- `project_plan.md` for documentation

## Possible Challenges

- Understanding how JavaScript interacts with HTML
- Working with browser events
- Updating the DOM after data changes
- Understanding asynchronous browser behaviour
- Using JavaScript objects and arrays instead of relying on Python-style patterns
