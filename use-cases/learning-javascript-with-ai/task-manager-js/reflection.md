# Reflection Questions

## 1. Which prompting strategies were most effective for my learning style?

The conceptual-understanding and guided-implementation strategies were the most effective.

The conceptual prompts helped me understand why JavaScript works differently from Python before I started writing code.

The guided implementation was also helpful because it allowed me to build the program step by step while learning the meaning of each JavaScript statement.

## 2. What surprised me about JavaScript?

I was surprised by how closely JavaScript works with HTML and browser events.

Unlike a basic Python script that normally runs from top to bottom, JavaScript applications often wait for events such as button clicks, keyboard input, or page loading.

I was also surprised by the importance of functions, objects, callbacks, and array methods in JavaScript.

## 3. How did my Python mental models help or hinder my learning?

My Python knowledge helped me understand variables, conditions, functions, lists, dictionaries, and loops.

Python lists helped me understand JavaScript arrays, while Python dictionaries helped me understand JavaScript objects.

However, Python sometimes made me expect JavaScript to behave synchronously. I also initially thought JavaScript objects worked exactly like Python dictionaries.

## 4. What would I do differently in my next learning session?

I would begin building a small project earlier instead of studying many concepts separately.

Building the Task Manager helped me understand how variables, functions, arrays, objects, events, DOM manipulation, and Local Storage work together.

I would also test each feature immediately after implementing it.

## 5. What gaps remain in my understanding?

I still need to improve my understanding of:

- Closures
- Scope
- JavaScript modules
- Promises
- Async/Await
- Fetch API
- REST APIs
- Node.js
- Express
- React
- Automated testing

# Three Final Key Learnings

## Learning 1

JavaScript is event-driven and is commonly used to respond to actions that happen in a browser.

## Learning 2

DOM manipulation allows JavaScript to create, change, and remove HTML elements dynamically.

## Learning 3

Local Storage allows a web application to save simple data in the browser and retrieve it after the page is refreshed.
