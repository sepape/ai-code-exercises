# Learning JavaScript with AI

## Project Overview

This repository contains my completed exercise for learning a new programming language using structured AI prompting techniques.

My source language is Python, and my target language is JavaScript.

The exercise includes a learning journey plan, conceptual comparisons, guided implementations, advanced prompting techniques, a practical mini-project, code review, refactoring, and reflection.

## Learning Goals

- Understand JavaScript fundamentals.
- Compare JavaScript concepts with Python.
- Build practical web applications.
- Learn DOM manipulation and browser events.
- Use Local Storage to save data.
- Improve JavaScript code through AI-assisted review.

## Exercise Sections

### Part 1

Created a structured JavaScript learning journey.

### Part 2

Applied the four-step prompting strategy:

1. Conceptual understanding
2. Step-by-step breakdown
3. Guided implementation
4. Understanding verification

### Part 3

Practised advanced prompting techniques:

- Using context effectively
- Promoting deep understanding
- Learning through teaching
- Using AI as a tutor

### Part 4

Built a Task Manager web application using HTML, CSS, and JavaScript.

## Task Manager Features

- Add tasks
- Validate empty input
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Save tasks in Local Storage
- Load tasks after refreshing the browser
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser DOM
- Local Storage
- Visual Studio Code
- Live Server
- Node.js

## Running the Task Manager

1. Open the project in Visual Studio Code.
2. Open the `task-manager-js` folder.
3. Right-click `index.html`.
4. Select `Open with Live Server`.
5. Use the application in the browser.
