# FastAPI Notes

## What is FastAPI?

FastAPI is a modern Python framework used to build APIs.

## Key Features

- Very fast
- Automatic documentation
- Uses Python type hints
- Built-in validation
- Async support

## Comparison

FastAPI

- Faster than Flask
- Easier validation
- Automatic Swagger documentation

Flask

- Lightweight
- Requires additional libraries

Django

- Full web framework
- Better for complete web applications
